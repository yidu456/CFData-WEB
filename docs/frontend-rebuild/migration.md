## 7. 后端已有但不是当前 Web 功能的清单

| 能力 | 当前入口/限制 | 本次如何处理 |
|---|---|---|
| CLI 交互菜单、按配置快速启动、自定义参数向导 | `-cli`、`-cli qs`；创建/读取/保存 JSON，参数校验、帮助、退出 | 登记并保持配置兼容，不默认搬进 Web |
| 定时任务开关、状态和频率 | CLI 菜单；仅 Linux+systemd+root；按天/周/月；使用配置启动 CLI；非交互代理警告可能中止任务 | 若要 Web 调度，需新增后端接口，不是前端换布局即可 |
| 自定义 DNS 和系统 DNS 失败回退 | 启动参数/配置；默认 223.5.5.5、8.8.8.8，显式指定时强制使用 | 保留后端行为；没有 Web 修改入口 |
| 监听地址/端口、用户名/密码、会话有效期 | 启动参数 | 不做虚假的前端设置项；远程部署应启用认证 |
| 调试等级、CLI 颜色与进度开关 | 启动参数/CLI 配置 | 不当成已有 Web 开关 |
| CLI 导出与自动上传 | 支持字段、范围、类型、合格筛选、Token 文件、GitHub 快速文件上传、edgetunnel 等 | 与浏览器凭据管理区分，不修改 CLI 能力 |
| 登录 JSON 请求、退出登录端点 | HTTP 后端已有，主页无完整操作入口 | 标记后端能力，UI 补入口需要在设计中确认 |

## 8. 独立 Cloudflare-BestIP 仓库

为防止“所有功能”混淆，单独登记；本次没有在该仓库创建分支或修改文件。

- Worker 从 `KV_NAMESPACE` 读取 ipv4/ipv6 结果和各自更新时间。
- `/bestipv4`、`/bestipv6` 返回对应纯文本 IP 列表；整体数据不存在或对应地址族不存在时返回 404。
- 看板具有 IPv4、IPv6、其他项目三个标签；展示 IP、Cloudflare 原生/其他类型判断、数据中心、地区码、丢包、延迟、速度、更新时间。
- 兼容 6/7/8 字段的已有结果格式；提供 CNAME/使用说明、更新时间和相关项目外链。
- `BestIP.sh` 按最新/指定版本与 Linux/macOS 架构下载上游程序；已有配置时只更新二进制。Docker 包装和 IPfile 地址素材属于部署/来源，不是 CFData 当前 Web 功能。
- 实际 BestIP 扫描、DNS 更新和定时逻辑来自下载的上游二进制，不能仅凭此仓库看板文案认定已完整审计。
- **当前 CFData 发布目标是 GitHub/edgetunnel，没有 Worker KV 写入接口。** 将它们连成一体是新增集成，不是保留已有功能。

## 9. 迁移中不能悄悄改变的行为与需确认的缺口

| 项目 | 当前事实 | 重构处理原则 |
|---|---|---|
| “恢复默认”语义 | 只删除服务端缓存 | 改清晰名称；若增加真正重置，必须单独定义范围 |
| 复验与自动测速联动 | 非标自动测速默认强制跟随复验 | 显式展示阶段；解耦需确认，不能凭 UI 喜好改变 |
| 官方自动流程所有者 | 前台浏览器、后台服务端分别串联 | 必须测试前台到后台每阶段转换，防重测/断链 |
| 后台“恢复” | 摘要+未来事件+特定最终结果，非完整历史回放 | 不宣称跨重启恢复/全历史同步 |
| 后台自动上传 | 浏览器收到完成事件后发请求 | 没有连接时不保证发布；要保证需后端新增发布编排 |
| 三种筛选作用域 | 任务门限、表格过滤、复制/导出过滤不同 | 清晰标注“对哪些数据生效”，保留原始结果 |
| 自动上传范围 | 默认字段、全量结果、独立去重 | 不突然改成仅可见行或默认 20 行；需要改变则先确认 |
| 参数保存不完整 | 不含复验/自动上传选择及文件内容 | 区分旧缺口与能力；迁移决策需列明保存范围 |
| compact 不只是隐藏列 | 后端可省掉 9 个完整字段 | 新 UI 切“完整”不能凭空恢复；要即时展开需后端保留完整数据 |
| 官方导出字段比表格少 | 表格有丢包/最小/最大/平均延迟，默认导出集较少 | 保留显示能力，扩展导出字段作为明确改进 |
| GitHub 快速文件上传入口 | 结果操作要求已有结果才能打开 | 移到独立发布入口更合理，但属于入口可用性改进 |
| edgetunnel 追加失败 | 读取失败会覆盖上传 | 必须说明风险；建议后续改为读失败终止，而非无提示复制旧行为 |
| 认证过期体验 | WS 返回 401，但旧页面只有常规重连 | 新体验需区分认证失效；后端没有现成 auth 状态查询接口 |
| WebCrypto 能力 | 普通非安全 HTTP 环境可能不可用 | 不丢本次上传；清楚说明凭据不能持久保存 |
| Android 下载适配 | 包装层依赖全局 downloadFile | 桌面模块化不能破坏原生导出 |
| 停止与完成事件顺序 | 专用完成数据之后还可能收到通用任务事件 | 保留部分结果与失败终态，不只用一个 running 布尔值 |
