### G02 非标优选工作流

输入、扫描参数和结果属于同一任务；链路复验是此工作流的可选阶段/后续动作，不是全局代理设置。

| 编号 | 功能 | 状态与边界 |
|---|---|---|
| N01 | 本地 TXT/CSV 文件输入 | Web 已有；显示文件读取结果/失败；浏览器传文本给后端，不是上传到永久文件库 |
| N02 | 网络 URL 输入 | Web 已有；必须是 HTTP/HTTPS，与文件互斥；由后端获取内容 |
| N03 | 解析多种端点格式 | 后端已有；IP/域名、空格端口、冒号端口、方括号 IPv6、URL、带表头 CSV 等；无有效目标需反馈 |
| N04 | 去重、使用备用端口、域名解析 | 后端已有；保留原始主机来源；一个域名最多扩展 50 个解析地址 |
| N05 | 扫描并发、延迟阈值、扫描合格数量上限 | Web 已有；默认 100/0ms/1000；合格数量上限必须大于 0，不能标成 0=无限 |
| N06 | 按数据中心约束扫描结果 | Web 已有；留空不限制；不同于官方“选数据中心再详细测试” |
| N07 | TLS 开关与备用端口联动 | Web 已有；默认 TLS 开启/443，关闭时默认 80；有效端口为 1-65535 |
| N08 | TCPing/HTTPing 扫描方式 | Web 已有；与 TLS、延迟门限一起影响测量，不应放成纯显示设置 |
| N09 | 自动测速开关与测速并发 | Web 已有；关闭时并发置 0，开启时从 0 恢复为 5；并发 1 更适合准确测速 |
| N10 | 公共/自定义探针与链路复验 | Web 已有；扫描后复验及对已有结果手动复验；后者需确认会剔除候选 |
| N11 | 复验可用性判断 | 后端已有；TCP+TLS+HTTP、成功状态码、探针 JSON 标记和有效出口 IP，不是仅检查端口可连接 |
| N12 | 非标实时扫描与测速更新 | Web 已有；更新同一个 IP:端口结果，不把测速消息追加成重复行 |
| N13 | 最终 CSV 表格与输出文件名 | Web 已有；默认 `ip.csv`，后端写本地文件并回传 headers/rows；浏览器下载是另一条输出路径 |
| N14 | 精简/完整结果展示 | Web 已有；后端也受 compact 参数影响；完整模式包含协议详情，见字段清单 |
| N15 | 完成后手动批量测速、继续测速 | Web 已有；操作全量当前结果，不仅是表格筛选后可见的结果 |
| N16 | 非标结果自动上传 GitHub | Web 已有；账户与格式选择独立于官方；当前自动上传不支持 edgetunnel |

主要依据：`startNSBTask`、`startNSBReallink`、`runNSBTask`、`runNSBReallinkTask`、`parseNSBInputs`、`resolveHostToIPs`。
