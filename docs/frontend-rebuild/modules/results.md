# 结果浏览与输出

以下编号记录现有功能/兼容约束；未来建议另行标注。源码位置均相对 CFData-WEB 仓库根目录。

### G05 结果浏览、筛选与排序

结果应区分 **官方扫描结果、官方详细结果、非标结果**。共用操作语言，不必共用完全相同的列。

| 编号 | 功能 | 状态与边界 |
|---|---|---|
| R01 | 三种结果视图和结果数量 | Web 已有；官方还有数据中心汇总；不要用一张“IP 列表”丢掉详细测试指标 |
| R02 | 非标精简/完整字段 | Web 已有；完整协议信息可用详情或展开呈现，不要求保留 25 列旧表格 |
| R03 | 合格/不合格/全部筛选 | Web 已有；依据当前测速状态和速度门限，不能混成“扫描连接成功” |
| R04 | IP 类型筛选 | Web 已有；主要用于混合地址的非标结果；官方地址族由任务选择，不必重复筛选入口 |
| R05 | 延迟和丢包筛选 | Web 已有；严格低于门限；0ms/100% 表示不限制；未知值与失败值需按现行规则处理 |
| R06 | 自定义三层排序优先级 | Web 已有；丢包、延迟升序，速度降序；重复优先级去重，稳定保留相同值顺序 |
| R07 | 未测速/失败排序 | Web 已有；数值速度在前，未测速在后，失败更后；不按原始字符串排序 |
| R08 | 官方延迟排序口径 | Web 已有；自定义排序依次比较最小/最大/平均延迟，导出的 latency 为平均延迟 |
| R09 | 点击 IP/端口复制与 IP 外部详情 | Web 已有；提供 ippure 外链；域名来源提示；需保留复制反馈与备用复制方式 |
| R10 | 实时增量结果转为最终结果 | Web 已有；最终 CSV/批量快照替换或合并结果，不能出现重复行/丢失速度 |

重要：表格可见数据与全量数据分开。当前表格筛选不自动决定一键测速、复验、自动上传的目标范围。

主要依据：`openSortModal`、`applySortModal`、`getFilteredOfficialTestData`、`renderScanRowsCSV`、`renderIPCell`。

### G06 复制与导出：共享输出配置，不与上传账号混在一起

| 编号 | 功能 | 状态与边界 |
|---|---|---|
| E01 | 批量复制文本 | Web 已有；与点击单个 IP/端口复制是两种入口 |
| E02 | TXT/CSV 文件导出 | Web 已有；自定义文件名，追加时间戳，UTF-8 BOM，正确 MIME |
| E03 | 开始行/结束行 | Web 已有；默认 1-20，先按输出筛选再取范围；不是原始表格行号 |
| E04 | 输出 IP 类型、合格状态筛选 | Web 已有；复制与导出各自独立配置 |
| E05 | 导出延迟、丢包门限 | Web 已有；独立于表格筛选；复制弹窗没有同等门限字段 |
| E06 | 字段选择、全选、仅 IP:PORT、默认选择 | Web 已有；按结果类型提供可用字段，不强制显示所有不存在的数据 |
| E07 | 字段顺序调整 | Web 已有；当前上下移动；新 UI 可换交互但保留排序能力 |
| E08 | 自定义常量字段 | Web 已有；`标题:内容`，可指定 `key=标题:内容`，逗号分隔多项；选择与排序一起生效 |
| E09 | TXT 分隔符预设与自定义 | Web 已有；包括空格；地址与额外信息之间的 `#` 是现行输出格式的一部分 |
| E10 | IPv6 方括号开关 | Web 已有；`[IPv6]:端口` 或不加方括号，不应重复加括号 |
| E11 | 输出预览与空数据提示 | Web 已有；预览与实际内容采用一致格式和范围规则 |
| E12 | CSV 转义 | Web 已有；引号、逗号、换行需要正确转义，不得用简单 join 破坏内容 |

现行 TXT 始终以 IP:PORT 开头，再以 `#` 接非空附加字段；CSV 按字段顺序输出表头/值。TXT 并不是完全任意列的通用表格序列化器。

默认 TXT：官方 `IP:PORT#数据中心-落地区域`，非标 `IP:PORT#数据中心-源IP位置`。当前官方手动 CSV 字段集较少，不包含完整的最小/最大延迟列；那些指标仍必须在结果视图中保留。

主要依据：`getSelectedCopyRows`、`getCurrentExportRows`、`buildResultContent`、`formatCSVCell`、`downloadFile`。
