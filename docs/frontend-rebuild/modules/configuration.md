### G08 参数配置与外观偏好

任务参数、发布账号、浏览器偏好、服务器配置是四种不同数据，不应共用一个“全部保存/全部重置”含混入口。

| 编号 | 功能 | 状态与边界 |
|---|---|---|
| C01 | 保存当前任务参数到浏览器 | Web 已有；`cfdata-config`，官方/非标分别记录；不包含本地文件内容 |
| C02 | 加载浏览器保存参数 | Web 已有；不存在/JSON 损坏/存储不可用需反馈 |
| C03 | 自动加载来源选择 | Web 已有；关闭、localStorage、服务器配置文件三种 |
| C04 | 从服务器同步 CLI 配置 | Web 已有；`get_config` 只读返回 `cfdata-config.json`，前端映射旧/新键名 |
| C05 | 删除保存参数及自动加载偏好 | Web 已有；删除 `cfdata-config` 和 `cfdata-autoload`，不删除账户或服务器缓存 |
| C06 | 浅色/深色/跟随系统 | Web 已有；保存 `cfdata-theme`，跟随系统变化，Android 主题与状态栏联动 |
| C07 | 参数动态启用/禁用与默认值恢复 | Web 已有；自动测速、数据中心、TLS 备用端口、URL 预设等依赖关系 |

现状缺口：`readFormValues` 不保存链路复验选项和自动上传账户选择，虽然加载函数可以读取复验配置。不能声称当前“保存配置”覆盖所有功能；迁移时应决定补齐哪些参数并验证旧数据兼容。

没有现成 Web 接口保存整份 CLI 配置；唯一现有服务端配置写回特例是管理面代理。不能做一个“保存到服务器”按钮然后只写 localStorage。

主要依据：`readFormValues`、`applyConfigValues`、`mapCLIConfigToForm`、`autoLoadConfig`、`applyTheme`。

### G09 系统环境、诊断与数据维护

管理面代理、测试环境警告、地址库维护可以位于同一个系统区域，但必须是分开的操作组。

| 编号 | 功能 | 状态与边界 |
|---|---|---|
| M01 | 管理面代理查询、保存、清除 | Web 已有；支持 socks5/socks5h/http/https；展示程序配置/系统环境变量等来源 |
| M02 | 代理生效与持久化结果 | Web 已有；立即生效，写配置失败则重启丢失；清除程序代理后回退环境代理，不保证直连 |
| M03 | 测试前地区/代理环境检测 | Web 已有；使用后端 Cloudflare trace；检测失败/超时也需要警告 |
| M04 | 取消或倒计时后强制继续 | Web 已有；5 秒倒计时，本次页面会记住强制继续；`skipgeo` 在服务启动侧设置 |
| M05 | 精简 IPv4 地址库 | Web 已有；/24 子网 TCP:80 探测、多轮、命中数、原子覆盖 ips-v4.txt；需确认有破坏性 |
| M06 | 精简保护与停止语义 | 后端已有；没有活跃子网时保留原文件；中止后若已找到子网仍可能写入精简结果，不能标成“取消一定不写文件” |
| M07 | 清理服务端本地缓存 | Web 已有；删除 ips-v4.txt、ips-v6.txt、locations.json、GeoLite2-ASN.mmdb |
| M08 | 缓存清理互斥及逐项反馈 | Web 已有；其他连接也在运行任务时拒绝；分别返回已删/不存在/失败，提示重启后下载 |
| M09 | 地理位置和 ASN 数据可用性 | 后端已有；下载/读取失败时位置、ASN 字段可缺失，日志反馈；不能让缺元数据变成整个表格打不开 |
| M10 | 当前版本、更新检查和发行页 | Web 已有；当前/最新版本、有更新/检查失败状态、项目外链；不是在线自动升级程序 |
| M11 | 调试错误记录 | 后端/前端已有；启动配置控制等级，前端记录错误/未处理异常；没有现成 Web 调试日志下载接口 |

**管理面代理不代理扫描/测速目标流量。** 它用于上游列表/位置/ASN 下载、版本检查、GitHub/edgetunnel 等管理请求。测试环境警告是另一件事；地区检测请求和扫描任务都在后端发起，返回标签不能解读为远程浏览器所在地区。

**旧按钮“恢复全部默认配置”命名与行为不符。** 它实际上是 M07，不重置表单、主题、浏览器账户或 CLI 配置。新界面建议明确命名“清理服务端数据缓存”。

主要依据：`setManagementProxy`、`detectCloudflareTraceCountry`、`runCompactIPv4Task`、`resetAllConfigFiles`、`renderVersionInfo`。
