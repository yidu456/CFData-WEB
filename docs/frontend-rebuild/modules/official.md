### G01 官方优选工作流

这些能力必须属于同一业务工作流，不应拆成互不关联的“扫描工具”“数据中心工具”“测速工具”。视图可以分阶段展示。

| 编号 | 功能 | 状态与边界 |
|---|---|---|
| O01 | 选择 IPv4 或 IPv6 地址库 | Web 已有；不是同时扫描两种地址族 |
| O02 | 配置目标端口 | Web 已有；当前选项包括 HTTPS 443/2053/2083/2087/2096/8443，HTTP 80/8080/8880/2052/2082/2086/2095 |
| O03 | 配置扫描并发、扫描合格延迟 | Web 已有；默认并发 100、延迟 500ms；阈值会影响通过条件 |
| O04 | TCPing/HTTPing 扫描方式 | Web 已有；展示不同测量口径说明，不把两种模式的数值直接作同口径比较 |
| O05 | 本地地址库读取、缺失下载和子网抽样 | 后端自动执行；IPv4 按 /24、IPv6 按 /48 展开后抽样，不是遍历全部 IP |
| O06 | 实时扫描结果与完成后的排序 | Web 已有；保留 IP、端口、数据中心、位置及延迟 |
| O07 | 数据中心汇总 | Web 已有；数据中心、落地区域、城市、IP 数量、最低延迟 |
| O08 | 手动选择数据中心进行详细测试 | Web 已有；记录当前测试/已测试状态，支持重新测试数据中心 |
| O09 | 多次详细延迟测试 | Web 已有；TCPing 10 次、HTTPing 3 次，产出最小/最大/平均延迟和丢包率 |
| O10 | 自动详细测试与批量测速 | Web 已有；数据中心可指定，留空自动选择；测速达标数量为 0 时不执行测速 |
| O11 | 在详细结果中对单个 IP 测速或重测 | Web 已有；不是一个接受任意输入 IP 的独立 Web 工具 |
| O12 | 官方完成结果自动上传 GitHub | Web 已有；选择已保存账户和 TXT/CSV；不是自动上传 edgetunnel |

主要依据：`startOfficialTask`、`maybeStartOfficialAutoTest`、`showDCSelection`、`selectDC`、`runOfficialTask`、`runDetailedTest`。
