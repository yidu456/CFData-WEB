## 10. 功能不缺失的验收场景

每个 G 组的功能表作为迁移对照表；以下是必须串起来验证的跨模块场景，不是已经执行的测试结果。

- [ ] 官方 IPv4/IPv6、HTTPS/HTTP 端口、TCPing/HTTPing 都可扫描，模式/单位正确。
- [ ] 官方扫描完成有数据中心汇总，能选择、重新测试 DC，并保留三种延迟和丢包。
- [ ] 官方自动选 DC/指定 DC 流程完整，指定 DC 不存在时有明确反馈。
- [ ] 官方单 IP 测速、重测、一键测速、继续测速都可执行；达标上限 0 正确禁用。
- [ ] 官方测速限流、无达标、全部失败、部分成功不清空可用结果。
- [ ] 非标文件与 URL 互斥，读取/下载失败、空文件、无有效端点都可恢复操作。
- [ ] 非标 IPv4、IPv6、域名、多种 TXT/CSV/URL 端点格式、原始来源和备用端口都保留。
- [ ] 非标 TLS 与端口联动、DC 筛选、延迟门限、结果上限按后端规则执行。
- [ ] 非标复验的公共/自定义探针、自动联动、手动剔除确认、取消保留规则完整。
- [ ] 非标实时结果、排序快照、最终 CSV、一键测速更新后没有重复/丢失行。
- [ ] 未测速/达标/未达标/失败在表格、筛选、输出和继续测速中含义一致。
- [ ] 表格筛选和多层排序不破坏全量结果；与执行范围、输出范围明确区分。
- [ ] 批量复制与 TXT/CSV 导出支持范围、字段、顺序、常量字段、分隔符、预览、IPv6 方括号。
- [ ] CSV 对逗号/引号/换行正确转义；BOM、中文、时间戳文件名兼容。
- [ ] GitHub 结果上传与快速文件上传、账户增选删、记住/不记住 Token、三次重试、Raw URL 可用。
- [ ] edgetunnel 账户、密码记忆、追加/覆盖确认和读取失败反馈完整。
- [ ] 两个模式的自动 GitHub 上传分别配置；范围和重复完成事件行为正确。
- [ ] 保存/加载/删除浏览器参数、自动加载、服务器同步、旧键名兼容，不误删账号/主题。
- [ ] 管理代理保存/清除/写盘失败/环境回退正确，扫描测速不经过管理代理。
- [ ] 地区检查失败/超时、警告取消、倒计时强制继续、skipgeo 都有合理状态。
- [ ] 精简库的多轮进度、无命中保护、覆盖确认、停止后结果，以及缓存逐项清理反馈正确。
- [ ] 前台断线取消、后台刷新不中断、摘要发现、跟随、最终结果、后台停止都正确。
- [ ] 各阶段转入后台和切换任务类型不重复启动自动步骤；多连接争抢任务有反馈。
- [ ] 失败/停止/部分完成收到 task_complete 后不会变成假成功；已有数据不丢。
- [ ] 启用/禁用认证、错误密码、过期重新建连、HTTP 页面与 WS 认证一致。
- [ ] 浅色/深色/自动主题和手机布局可用；所有设置、结果动作和确认操作可达。
- [ ] Android 系统文件选择、原生导出、状态栏、外链、返回键与销毁进程行为验证。
- [ ] 位置/ASN 不可用、版本检查失败、无结果、存储/加密不可用仍能使用其他能力。
